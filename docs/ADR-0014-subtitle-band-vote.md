# ADR-0014：字幕带投票 —— 试过、不适用、边界在此

- **状态**：**Rejected**（2026-11-09）
- **影响文件**：`subs.mjs`（投票逻辑降级为诊断统计）、`pipeline.mjs`（不变）
- **相关**：ADR-0013（OCR 候选区间）、ADR-0012（网格去重）

## 动机

[Video-Subtitle-OCR](https://github.com/wm1634208243/Video-Subtitle-OCR) 的 README 里有一条优化：

> **默认跨多帧投票锁定稳定字幕区域，减少车牌、Logo、画面文字等非字幕内容进入 OCR。**

思路是：**字幕位置在全片是相对固定的**，所以可以先投票找出「字幕带」，然后只在这个区域里做检测——**省掉大量无字区域的像素计算。**

这个方向和当时的痛点吻合：**57 秒视频的字幕提取要 86-186 秒，检测是大头。**

## 实现

```
稀疏探测 16 帧
  → 命中框按位置聚类（x0/40, y0/20 粗粒度分桶）
  → 同一桶出现 ≥30% 命中 → 判为「稳定字幕带」
  → 候选区间只算落在带内的命中
  → 区间外不检测
```

**降级保护**：**如果一条带都没聚出来，回退到「全部命中」**——**保证不会因为投票失败而丢掉所有字幕。**

## 实测结果（57 秒「大肥鱼配饰分析」）

```
[subs] 稀疏探测 16 帧，候选 14
[subs] 字幕带投票：14 个命中框聚成 0 条稳定带
[subs] 候选区间 1 段，覆盖 57.5s / 57.5s
det 115 帧（全片）
[subs] 完成 79.2s，字幕 25 条
```

**一条带都没聚出来。** **降级逻辑生效 → 候选区间覆盖全片 → det 仍是 115 帧。**

**没有获得任何检测削减。**

## 失败原因

**这个视频的内容形态和假设不匹配。**

**「配饰分析」是逐件特写**：**鞋子在画面下方、裙摆在中间、围裙在腹部、头发在上方**——**每个镜头的字幕跟着画面内容走，位置全都在变。**

**全片位置稳定这个前提，在这里根本不成立。**

**14 个命中框分散在 4-5 个不同位置，每个位置簇只有 1-2 票，凑不够 30%。**

## 一个我犯的计算错误

**我最初用「占 14 个命中框的比例」算阈值，这是错的。**

**正确的分母是 16 个探测帧，而且同一帧的多个框不能重复计票。**

```
按命中框算：30% → 4.2 票（我的错）
按探测帧算：30% → ceil(16×0.3) = 5 帧（正确）
```

**这两个是不同的指标，不能混用。**

**但这个错误不是失败的主因**——**即使阈值算对，字幕位置分散本身就注定聚不出稳定带。**

## 为什么不去调阈值救它

**霁璃的判断**：

> **这里首先不是票少，而是「全片位置稳定」这个假设与当前视频不匹配。增加采样能改善统计，但不能把跟着画面移动的文字变成全片固定字幕。**
>
> **把 `x0/40` 改成 `x0/120`，只是加粗分桶，可能把不相干的位置硬凑成一簇。凑出带不等于找对带。**

**所以**：**降低阈值或粗化分桶，都能「终于产出稳定带」，但那个带可能是硬凑的。**

**不调。**

## 决定

**① 撤回稳定带的跳检和缩区间权限**

**空间统计模块只产出诊断信息**（**位置分布、支持帧数、候选区域**），**不再影响检测范围。**

**约束写死**：

```
空间统计为空 → 不改变时间候选
低支持率 ≠ 没有字幕（不能据此跳过）
水印判别独立处理，不靠「固定位置」推导
```

**② 模块拆成三个独立部分**

| 模块 | 职责 | 拿不到输入时 |
|---|---|---|
| **空间统计** | 位置分布、支持帧数 | **不影响其他模块** |
| **时间候选** | 原有逻辑（稀疏探测 → 区间） | **行为完全不变** |
| **执行策略** | 时间段 + 可选空间提示 → 检测任务 | **无提示 = 按时间段全跑** |

**③ 不接「读图排序」**

**排序只有在「更早返回第一批结果 / 支持中途取消 / 有限预算下优先高价值内容」时才有价值。**

**我们关心的是全片完成时间，排序不减少总工作量，反而多一道调度。**

**默认关闭，只记录空间统计。**

## 水印过滤：单独验收，且证据不足

**同一次运行里，水印过滤是有效的**：

```
[subs] 水印候选位置 1 处（跨 72 帧占比 >40%）
screenText: 33 条 → 7 条
```

**但「删掉了多少」不等于「删对了」。**

**固定字幕、栏目标题、长期驻留的状态栏也可能被当成水印。**

**验收必须导出被删掉的结果逐条核对**：

- **真正的水印删了多少**
- **正文、字幕、有效标注误删了多少**
- **25 条字幕的文本和时间有没有变化**

**本测试集没有误删有效文字，才算这条过滤在本测试集通过。**

**而且——水印过滤的收益不能记到字幕带投票头上。**

## 不可外推

**本次结果只说明**：

> **在位置变化明显的视频上，全片稳定带策略未形成有效空间约束，降级后仍检测全部 115 帧，未获得预期的检测削减。**

**不外推为**「所有固定字幕视频均不适用」——**固定字幕、单机位讲解、录屏这类内容，稳定带很可能有效。**

**只是这个测试集不是那类内容。**

## 数据可信度备注

**这轮对比中出现过两个污染源**：

1. **温度与并发不同**（**39℃/3 路、41℃/2 路、36.5℃/4 路**）—— **时间不能直接作因果比较**
2. **一次抢存的视频是残缺文件**（**只有前 16 秒**）—— **那次的 32 帧 / 8 条字幕不能算数**

**后续做对照实验必须**：**同一帧集、同一并发、同一温度档、同一份完整视频。**

## 一句话

> **把无效优化撤干净，也是一项有效的工程结论。**
