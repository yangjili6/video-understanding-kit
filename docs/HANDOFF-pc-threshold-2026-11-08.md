# 电脑端验证：新阈值（2026-11-08）

> 对应 `21d4e76`。上一轮你在 i9-14900HX 上的 16 路标定已经合并采纳，这轮验证**阈值调整后的推荐值变化**。

## 一、改了什么

```diff
- const passed = eff >= 0.40 && gain >= 0.08
+ const passed = eff >= 0.40 && gain >= 0.10 && absSave >= 0.3
```

两条改动：

1. **边际阈值 8% → 10%**：你上轮回执里指出 8% 低于测量噪声（A 组各档极差 3~10%），出现过 4 路 7.9%「差 0.1% 被误杀」
2. **新增绝对节省 ≥ 0.3s**：多开一个 worker 至少得换回 0.3 秒，否则不值得
