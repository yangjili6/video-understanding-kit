## §1 OCR 几何阈值：整片输出 0 条

**症状**：`fish` 210 秒、420 抽帧，`subsCount = 0`，但画面里明明有烧录字幕。

**取证**：对 `f-0001.jpg`（960×540）单独跑 `detect()`，拿到 6 个 box，其中字幕行是：

```
x0=383  y0=450  x1=575  y1=485   →  w=192  h=35
```

而 `subs.mjs` 当时的过滤条件用的是 `ffprobe` **原始分辨率**（1280×720）：

```js
w > W * 0.3        // 384   ← 192 不够
y0 > H * 0.65      // 468   ← 450 不够
```

两条全灭。根因是**坐标系错配**：OCR 帧由 `scale=960:-1` 缩放，box 在 960×540 空间，阈值却按 1280×720 算。

**修复**：按帧坐标判定，并加居中度挡角标。

| 判据 | 旧（对 1280×720 生效） | 新（对 960×540 生效） |
|---|---|---|
| 宽度 | > W×0.3 = 384 | > 帧宽 8% = 77 |
| 纵向 | y0 > H×0.65 = 468 | y0 > 帧高 60% = 324 |
| 字高 | 仅 > 15 | 帧高 2%~16% |
| 居中 | 无 | \|cx − 480\| < 帧宽 22% |

居中度这条实测很关键：字幕 cx=479（画面中心 480），updream 角标 cx=120、bilibili 角标 cx=876，一条规则同时挡掉两个水印。

**结果**（`fish` 前 1/3，140 帧 / 0–70s）：

```
旧规则命中   0 帧
新规则命中  85 帧（60.7%）
detect 耗时 74.7s（0.53s/帧）
```

抽样识别 8 条，置信度 0.99~1.00：

```
 0.0s 1.00 家规第一条
 5.5s 0.99 就一口就尝一口嘛
10.5s 0.99 你身上有大白饭的味道
25.5s 0.99 啊请问你们是谁
33.5s 1.00 就抱一下下好不好
43.5s 1.00 你想躲多久都可以
49.5s 1.00 家人可是我什么都想不起来
58.5s 1.00 我记得就够了
```

端到端复跑（`fish-1/3` 70 秒，OCR + ASR 全开）：`subsCount 20`，`asrCount 3`，耗时 201s。

## §2 OCR 预探测：无字幕片不再白跑

**动机**：`§1` 的 420 帧全量 OCR 约 220 秒（0.53s/帧），如果片子压根没有硬字幕，这两百多秒纯属浪费。

**做法**：全量前均匀抽 `SUBS_PROBE_N`（默认 12）帧试 `detect`，一帧都没命中就返回空。保守策略——只要有一帧命中就照常全量。

**结果**：

| 素材 | 预探测 | 字幕提取耗时 | 输出 |
|---|---|---|---|
| `cat` 15s（无硬字幕） | 命中 0 → 跳过全量 | **7.2s** | 0 条 |
| `fish-1/3` 70s（有字幕） | 命中 >0 → 全量 | 73.9s | 20 条 |

pipeline 日志（`cat`）：

```
[subs] 跑字幕提取（PP-OCR 硬字幕链路）...
  [subs] 预探测 12 帧，命中 0
  [subs] 全程没有字幕行，跳过全量 OCR
[subs] 完成 7.2s，字幕 0 条
[timing] 字幕提取: 7.2s
```

210 秒长片若同样无字幕，按 0.53s/帧推算可省约 210 秒（此项为推算，未单独实测）。

## §3 ASR 静音阈值

**素材**：`small`（30s 实拍，mean_volume −25.7dB，max −2.9dB）。

先确认不是电平问题：整体平均电平 −25.7dB，说明全程"有声音"，只是大部分是音乐与环境音。

| 阈值 | 语音段 | 识别条数 | 内容 |
|---|---|---|---|
| −30dB / d=0.4（默认） | 7 | 4 | 我们 / 啊啊 / 你用户 / 我我只是在看金鱼的学习资料啦 |
| −35dB / d=0.4 | 9 | 5 | 我们 / 游戏 / 没有了 / 嗯用户 / 我我只是在看金鱼的学习资料啦 |
| −40dB / d=0.6 | 8 | 5 | 啊 / 游戏 / 没有 / 啊啊 / 用惑我我只是在看金鱼的学习资料啦 |
| −50dB / d=0.8 | 4 | 2 | 你们 / 啊啊用惑我我… |

**结论**：−35dB 在实拍素材上确实有收益（+1 条有效信息），但**同一设置在动画片上会反向恶化**（§5：13 → 9 条）。所以默认值不动，只开放 `ASR_SILENCE_DB`。

## §4 ASR 分段方式（同一段 30s 音频）

| 策略 | 段数 | 条数 | 备注 |
|---|---|---|---|
| 静音切分 −30dB | 7 | 4 | 现状 |
| 静音切分 −40dB | 8 | 5 | |
| 静音切分 −50dB | 4 | 2 | 段太长，跑偏 |
| 固定 8s 窗 / 步长 7s | 5 | 5 | 「旅行」为明确误识别 |
| 不切分（整段 30s） | 1 | 1 | 文本对，但时间戳失效 |

固定窗口的失败点很具体：它无视音频内容，把句子切在任意位置，且重叠区会诱导模型把前后句拼成不存在的词。

## §5 长段等分（本次最大收益）

**素材**：`fish`（210s 动画，纯人声，−35dB 下只切出 2 个语音段：86.45s 与 123.86s）。

| 配置 | 段数 | 条数 | 耗时 | 文本质量 |
|---|---|---|---|---|
| −35dB，**不切分** | 2 | 2 | 123.6s | 「家规第一条…才可以**冻**筷子」「被骂会**划管**」「**这知了酱汁了**」 |
| −35dB，切分 ≤25s（bug 版） | 5 | 5 | 158.7s | 前 4 段正常，最后 124s 段仍是整段（见下方 bug） |
| −35dB，切分 ≤25s（修复后） | 9 | 9 | 97.8s | 「**动**筷子」「保管的意义就是等他回来拿」 |
| **−30dB，切分 ≤25s（默认）** | 未记录 | **13** | **87.4s** | 最佳；「我替你们每个人保管过一些东西这一份是他的」捞回 |
| −30dB，不切分（原始端到端） | 8 | 8 | 未单独计时 | 含上述错字；此行为端到端调用（210s 全流程 574.8s，含 OCR） |

**中间踩的坑**：切分逻辑第一版用 `Number.isFinite(Number(s.end))` 判断段尾——最后一段用 `end: null` 表示"到结尾"，而 `Number(null) === 0`，于是一个 124 秒的段被当成 0 秒直接放过，日志显示"2 段 → 5 段"（只切了第一段）。改成显式判空后变成 9 段。

**代价**：cue 数量从 8 增加到 13，粒度从"整片级"降到 ~20 秒级——这正是 `video_frame` 定位所需要的时间精度。

## §6 语气词过滤

`isNoiseOnly()`：去标点后长度 ≤ 3 且全是语气字才丢弃。

| 素材 | 过滤前 | 过滤后 | 被丢的内容 |
|---|---|---|---|
| `small` | 4 | 3 | 「啊啊」（20.9–24.1s，来自 BGM） |
| `fish` | 13 | 13 | 无（零误伤） |

「好像」（2 字，有语义）在动画片里出现并保留，说明不能简单地按长度砍。

## §7 降噪（负结果）

下载 `gtcrn_simple.onnx`（523KB），用 `sherpa-onnx` 的 `createOfflineSpeechDenoiser` 先降噪再识别。

| | 结果 |
|---|---|
| 原始整段 | 嗯诱惑我我只是在看金鱼的学习资料啦 |
| 降噪整段 | 啊啊诱惑我我只是在看金鱼的学习资料啦 |

5 秒分段对比（原始 → 降噪）：

```
 0-5s   啊   → 好笨
 5-10s  旅行 → 是
10-15s  嗯   → 哎我
15-20s  嗯   → 嗯
20-25s  啊啊 → 啊啊
25-30s  用户我我只是在看金鱼的学习资料啦 → 诱惑我我只是在看金鱼的学习资料啦
```

**结论**：降噪不是在改善，只是在换错法。这段素材的问题是**人声本身太轻太短**（信息不足），不是信噪比低。降噪不增加信息量，未采用。

## 复现方式

```bash
# 1) 环境（ffmpeg / ImageMagick 来自扩展中心）
export PATH=$PREFIX/extensions/ffmpeg/bin:$PREFIX/extensions/imagemagick/bin:$PATH

# 2) 拉取素材
node dl-bili.mjs BV17rng6mEmT  /tmp/fish.mp4      # 动画 210s
node dl-bili.mjs BV1Bjnr6NEJG /tmp/smallfish.mp4  # 实拍 30s
node dl-bili.mjs BV12tHr6DEkD /tmp/cat.mp4        # 动画 15s（无字幕）

# 3) 只跑 ASR，改阈值/切分上限做对照
ASR_SILENCE_DB=30 ASR_MAX_SEG=25 node -e "
  import('$PWD/dsh-plugin/lib/videokit/asr.mjs').then(m => {
    const cues = m.transcribeVideo('/tmp/smallfish.mp4', { outDir: '/tmp/asr-out' })
    for (const c of cues) console.log(c.s + '-' + c.e + 's', c.text)
  })"

# 4) 只跑 OCR 链路（pipeline 会打印预探测与字幕条数）
node pipeline.mjs --video /tmp/cat.mp4 --out /tmp/ocr-out --subs
node pipeline.mjs --video /tmp/fish.mp4 --out /tmp/ocr-out2 --subs

# 5) 单帧 OCR 取证（看 box 与阈值判定）
node -e "
  import('$PWD/dsh-plugin/lib/videokit/lib/ocr-pp.mjs').then(async m => {
    console.log(await m.detect('/tmp/ocr-out/frames/f-0001.jpg'))
  })"
```

> 注：`dl-bili.mjs` 是临时脚本（B 站 view API 取 cid → playurl 取 durl → 带 Referer 下载），未入库。
